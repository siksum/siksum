코드 유사도 기법을 활용한 스마트 컨트랙트 공격 표면 탐지 방법

오픈소스 컨트랙트를 고쳐 쓸 때 원본과 달라진 코드를 유사도로 먼저 찾아 우선 검토하는 방법을 제안했습니다. 전체를 같은 비중으로 보지 않고 위험한 영역을 좁힙니다.

역할
제1저자, 발표

제안 배경

내용

오픈소스 컨트랙트를 복제해 고칠 때 원본에 없던 결함이 생깁니다.

피해 규모
2022년에는 탈중앙 금융(DeFi) 예치 자산의 약 6%인 30억 달러가 해킹으로 탈취됐습니다.
실제 사례
2021년 Uranium Finance는 Uniswap V2를 복제하며 비율 설정을 잘못 고쳐 약 5천만 달러를 잃었습니다.

선행 연구

내용

기존 도구는 정해진 패턴만 찾았고 코드 유사도를 보안 점검에 쓴 사례는 드물었습니다.

기존 도구
정해진 패턴으로 찾는 도구는 논리적 관계를 탐지하지 못하고 잘못된 경고가 많습니다.
유사도 연구
기존 코드 유사도 연구는 복제 비율을 재는 데 그쳤습니다.

해결책

내용

원본과 달라진 부분을 유사도로 먼저 찾고 그 부분을 우선 검토합니다.

방법 1단계
코드의 문법 구조와 실행 경로를 비교해 수정된 부분과 취약점이 생기기 쉬운 곳을 찾습니다.
방법 2단계
두 특징을 신경망으로 학습해 유사도를 계산하고 위험한 영역에 우선순위를 매겨 경고합니다.

입증

내용

논문 본문에는 정량 실험이 없고 사례 설명과 발표 시연으로 뒷받침했습니다.

논문 본문
Uranium Finance 사례로 필요성을 설명한 정성 논의입니다.
발표 시연
유사도가 0.95를 넘는 함수에 비즈니스 로직 규칙을 적용하는 시연을 했습니다.
한계
시연 대상은 Uniswap V2의 유동성 추가 함수 두 개뿐입니다.

기여와 다음 단계

기여

복제한 코드에서 달라진 부분을 유사도로 찾아 점검 범위를 좁히는 방법을 제안했습니다.

역할
제1저자로 연구를 수행하고 직접 발표했습니다.
수상

후속 연구

향후 과제

저널 확장
