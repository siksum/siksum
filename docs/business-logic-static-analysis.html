제안 배경

내용

문법은 맞지만 자금 처리 순서나 조건이 틀린 코드는 자산 탈취로 이어집니다.

서비스 구조
탈중앙 금융(DeFi)의 대출 서비스는 예치, 인출, 대출, 청산으로 자금을 움직입니다.
피해 경로
실행 전에 권한이나 상태를 확인하는 코드가 빠지거나 잘못 놓이면 자산을 잃습니다.

선행 연구

내용

기존 도구는 정해진 패턴만 찾거나 시간이 많이 듭니다.

패턴 검사
알려진 패턴을 찾는 도구는 서비스마다 다른 자금 처리 로직을 검증하기 어렵습니다.
경로 탐색
실행 경로를 모두 탐색하는 도구는 코드가 복잡해지면 시간이 급격히 늘어납니다.

해결책

내용

자금이 움직이는 네 기능을 세 분석 계층으로 차례로 좁혀 가며 점검합니다.

점검 내용
자금이 이동하기 전에 확인할 조건이 코드에 있는지, 처리 순서가 의도대로인지 봅니다.
세 계층
문법 구조로 후보를 고르고, 실행 흐름으로 순서를 확인하고, 값의 의존 관계까지 추적합니다.

입증

내용

세 계층을 모두 쓰면 정밀도와 재현율이 1.00이었지만 평가 사례 수는 논문에 없습니다.

실험 설정
DeFi 해킹 사례로 기존 도구 두 개(Slither, Echidna)와 비교했습니다.
결과
계층을 더할수록 정밀도가 0.63, 0.93, 1.00으로 올랐고 재현율은 모두 1.00이었습니다.
분석 시간
평균 1.26초로 Echidna 1.98초, Slither 2.63초보다 짧았습니다.

기여와 다음 단계

기여

분석 계층을 더할수록 오탐이 줄어든다는 것을 수치로 보였습니다.

참여
공저자로 참여했습니다.
논문의 기여
확인 절차의 존재와 호출 순서를 검증하는 다계층 정적 분석 절차를 제시했습니다.

후속 연구

적용 범위를 넓히고 확인 코드를 추천하는 기능을 붙이는 것이 남은 과제입니다.

범위 확대
더 다양한 프로토콜과 최신 컨트랙트에 적용합니다.
자동 추천
빠진 확인 코드를 자동으로 추천하는 기능을 결합합니다.
