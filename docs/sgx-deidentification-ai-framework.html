개인정보보호를 위한 SGX 기반 학습데이터 비식별화 인공지능 학습 프레임워크

개인정보가 든 학습데이터를 관리자도 볼 수 없는 격리 영역 안에서 비식별화하고 학습하도록 설계했습니다. 클라우드 운영자가 접근해도 원본은 확인할 수 없습니다.

역할
공동 제1저자, 발표
게재
KCSE 2022, 제24회 한국소프트웨어공학 학술대회, 2022.01

제안 배경

내용

클라우드에 올린 학습데이터는 클라우드 운영자가 열람하는 것을 막기 어렵습니다.

기존 통제
암호화나 접근 통제는 일반 사용자를 막을 뿐 클라우드 운영자의 열람은 막지 못합니다.
실제 사례
2021년 '이루다' 서비스는 대화 데이터 노출로 3주 만에 중단됐습니다.

선행 연구

내용

기존 방식은 개인정보를 따로 구분해 저장하지 못하고 키 관리 부담이 큽니다.

기존 방식
데이터를 조각내 암호화하거나 블록체인에 분산 저장하는 방식이 제안되어 있습니다.
한계
개인정보와 일반데이터를 구분해 저장하지 못하고 키 관리에 공간과 성능 부담이 듭니다.

해결책

내용

관리자도 들여다볼 수 없는 격리 영역 안에서 분류, 비식별화, 학습을 모두 합니다.

격리 영역
CPU가 메모리 일부를 암호화해 운영체제나 관리자도 볼 수 없게 한 영역(Intel SGX)입니다.
개인정보
격리 영역 안에서 비식별화한 뒤 암호화해 클라우드에 저장하고 학습할 때만 가져와 복호화합니다.

입증

내용

구현과 정량 실험 없이 선행 연구 3건과 정성 비교한 논문입니다.

비교 대상
비용 효율성, 성능 효율성, 보안성의 세 지표로 비교했습니다.
결과
별도 키 관리 공간이 필요 없고 개인정보 분리 저장이 가능하다는 점을 장점으로 들었습니다.
한계
비용과 오버헤드 감소는 기대 효과이며 측정값이 아닙니다.

기여와 다음 단계

기여

클라우드 운영자까지 신뢰하지 않는 조건에서 학습데이터 처리 흐름을 설계했습니다.

역할
공동 제1저자로 연구를 수행하고 발표했습니다.
논문의 기여
학습데이터의 분류, 비식별화, 저장, 학습을 하나의 격리 영역 흐름으로 묶었습니다.

후속 연구

설계에 머문 프레임워크를 실제로 구현해 측정하는 일이 남았습니다.

구현과 측정
프레임워크를 실제로 구현해 벤치마크로 오버헤드를 측정할 계획입니다.
성능 분석
비식별화 기법 종류에 따른 모델 성능을 분석할 계획입니다.
