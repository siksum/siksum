Publications/PBFT 평가 프레임워크

Publication

프랙티컬 비잔틴 장애 허용 기반 블록체인의 확장성과 내결함성 평가 및 비교분석

연구마다 달랐던 PBFT 계열 합의 알고리즘의 평가 항목을 처리량, 지연시간, 내결함성으로 통일했습니다. 노드 수와 결함 조건이 달라도 같은 기준으로 비교할 수 있게 했습니다.

역할
공저자
게재
한국정보통신학회논문지, Vol. 26, No. 2, pp. 271–277, 2022.02
PBFT 처리량
59.3Mbps → 0.91Mbps

블록 1MB, 노드 100대 → 1000대, 정상 노드만

합의 성공률
99대까지 100%

전체 300대, 블록 1MB. 결함 노드가 f(약 1/3)를 넘으면 급감하고 2f(198대)부터 전부 실패

실험 노드 규모
100~1000대

100대 단위, Python 시뮬레이션

제안 배경선행 연구해결책입증기여와 다음 단계

제안 배경

내용

PBFT와 그 개선안을 같은 기준으로 시험하고 비교할 방법이 부족했습니다.

PBFT
일부 노드가 고장 나도 나머지가 같은 장부에 합의하게 하는 알고리즘입니다.
문제
모든 노드가 서로 메시지를 보내므로 노드가 늘수록 네트워크 부하가 커집니다.

선행 연구

내용

개선 연구마다 평가지표가 달라 서로 비교하기 어려웠습니다.

지표 불일치
시간 복잡도만 쓴 연구와 합의 지연, 처리량을 쓴 연구가 섞여 있었습니다.
도구 부재
기존 시뮬레이터는 작업증명 중심이어서 PBFT 계열을 평가할 수 없었습니다.

해결책

내용

평가 기준을 셋으로 통일하고 합의 부분만 갈아 끼울 수 있는 평가 구조를 만들었습니다.

구조
네트워크, 합의, 평가로 나눠 합의 알고리즘을 바꿔도 같은 조건으로 잽니다.
지표
확장성은 처리량과 지연시간으로, 내결함성은 견디는 결함 노드 수로 봅니다.

입증

내용

노드가 늘면 처리량이 급감했고, 결함 노드가 1/3을 넘으면 합의 성공률이 급감했습니다.

실험 설정
Python 시뮬레이션으로 정상 노드를 100대에서 1000대까지 늘리며 측정했습니다.
결과
블록 1MB에서 처리량은 59.3Mbps에서 0.91Mbps로 줄었고 300대 중 결함 99대까지 합의했습니다.
한계
평가 대상은 기본 PBFT 하나이며 개선 알고리즘과 비교한 실험은 없습니다.

기여와 다음 단계

기여

PBFT 계열을 같은 지표로 재는 평가 구조와 기본 PBFT의 기준 수치를 낸 논문입니다.

참여
공저자로 참여했습니다.
논문의 기여
처리량, 지연시간, 내결함성으로 재는 구조를 제시하고 기준 수치를 냈습니다.

후속 연구

이 연구에서 측정한 PBFT의 한계가 석사과정의 rPBFT 연구로 이어졌습니다.

향후 과제
이 프레임워크로 PBFT 개선 연구들을 정량 비교하는 것입니다.
이어진 연구
석사과정에서 고장 난 노드를 합의에서 제외하는 rPBFT를 제안했습니다.
