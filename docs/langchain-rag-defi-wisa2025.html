Enhancing DeFi Smart Contract Security via LangChain and Retrieval-Augmented Generation

컨트랙트를 함수 단위로 나눠 과거 DeFi 사고에서 비슷한 코드를 찾고 그 사고의 맥락을 LLM에 제공합니다. 가격 조작 판정의 근거와 문제가 된 함수 위치를 함께 제시합니다.

제안 배경

내용

DeFi에서 가장 흔하다고 본 가격 조작 공격의 탐지에 초점을 맞췄습니다.

상황
DeFi는 대출, 예치, 거래를 코드가 자동 처리하고 배포된 컨트랙트는 고칠 수 없습니다.
가격 조작
유동성 풀의 토큰 가격을 인위적으로 움직여 이득을 얻는 공격입니다.

선행 연구

내용

기존 정적 분석과 LLM 기반 연구는 오탐이 많거나 응답이 일관되지 않았습니다.

정적 분석
오탐이 많고 프로토콜이 하려는 일의 의미를 해석하지 못합니다.
LLM 연구
미세 조정한 LLM은 정확도 91%를 보고했지만 응답 일관성이 38%에 그쳤습니다.

해결책

내용

과거 DeFi 사고에서 비슷한 코드를 먼저 찾아 그 사고 정보를 LLM에 근거로 줍니다.

사례 검색
코드를 함수 단위로 나눠 해킹 사례 DB에서 비슷한 코드를 찾고 그 사고 정보를 LLM에 줍니다.
출력
LLM은 취약 여부와 문제가 되는 함수를 설명과 함께 내놓습니다.

입증

내용

가격 조작 사고 10건 중 8건에서 취약 함수를 정확히 식별했습니다.

실험 설정
2024~2025년 가격 조작 사고 10건을 정적 분석 도구, GPT-4o와 비교했습니다.
결과
제안 방법은 8건(F1 0.89), GPT-4o는 5건(F1 0.67), 정적 분석 도구는 0건을 식별했습니다.
해석 주의
GPT-4o는 후보 함수를 보통 6~7개씩 나열해 하나가 맞을 가능성이 높았습니다.

기여와 다음 단계

기여

과거 사고 검색을 LLM 분석에 결합한 논문입니다.

참여
공저자로 참여했습니다.
논문의 기여
가격 조작의 판정 근거와 취약 함수 위치를 함께 제시하고 기존 도구와 비교했습니다.

후속 연구

평가 대상이 가격 조작 10건뿐이어서 탐지 범위를 넓히는 것이 과제입니다.

한계
평가가 10건뿐이고 제안 방법도 그중 2건은 식별하지 못했습니다.
향후 과제
다른 공격 유형으로 범위를 넓히고 실시간 모니터링에 연동하는 것입니다.
