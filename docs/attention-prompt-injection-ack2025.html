어텐션 패턴 분석 기반 프롬프트 인젝션 탐지 시스템

금지어가 포함된 입력은 필터로 먼저 차단하고, 문맥 속에 숨은 공격은 모델의 주의 변화로 분석합니다. 탐지 정확도와 처리 속도를 함께 측정했습니다.

역할
공저자
게재
ACK 2025, 한국정보처리학회, 2025.11.07
성과
한국정보기술학술단체총연합회 회장상
제안 방법의 탐지 정확도
약 83%

악성 프롬프트 23개 기준, 금지어 필터 단독과 Attention Tracker 단독은 각각 43%

지연 시간 단축
44.6%

Attention Tracker 단독 약 734ms 대비 제안 방법 약 406ms

제안 배경선행 연구해결책입증기여와 다음 단계논문 원문

ICT융합보안크루 2기에서 수행한 연구입니다 →

제안 배경

내용

공격 문장은 자연스러운 말로 위장할 수 있어 한 가지 방법으로는 막기 어렵습니다.

공격 정의
악의적 입력을 정상처럼 꾸며 AI 언어 모델(LLM)이 의도하지 않은 동작을 하게 만듭니다.
간접 공격
문맥 조작이나 감정 호소처럼 자연스러운 문장으로 위장하면 탐지가 어렵습니다.

선행 연구

내용

기존 방법은 저마다 놓치는 공격이 있고, 모델을 돌리는 방법은 느리고 비쌉니다.

규칙 기반
키워드 차단에는 효과적이지만 우회에 약합니다.
어텐션 분석
모델의 주의가 주입된 지시로 옮겨가는 현상을 이용하지만 코드 삽입 공격에는 약합니다.

해결책

내용

가벼운 금지어 필터로 먼저 거르고, 남은 입력만 무거운 어텐션 분석에 넘깁니다.

1단계
금지어 필터가 전형적인 공격 키워드를 가진 입력을 먼저 차단합니다.
2단계
통과한 입력만 모델의 주의가 원래 지시에 머무는 정도를 점수로 계산해 판정합니다.

입증

내용

악성 프롬프트 23개로 정확도 약 83%와 지연 44.6% 단축을 확인했습니다.

실험 설정
여섯 유형의 악성 프롬프트 23개로 두 단독 방법과 비교했습니다.
결과
정확도는 약 83% 대 각 43%였고 평균 지연은 약 734ms에서 약 406ms로 줄었습니다.
한계
논문에 적힌 90% 향상은 43%에서 83%로 오른 상대 증가율입니다.

기여와 다음 단계

기여

규칙 필터와 어텐션 분석을 순서대로 묶으면 정확도와 지연이 함께 나아짐을 보였습니다.

참여
공저자로 참여했습니다.
논문의 기여
규칙 필터와 어텐션 분석의 결합 효과를 소규모 실험으로 보였습니다.
