ICT융합보안크루 2기

ICT Convergence Security Crew 2nd

4개 대학 10명의 AI 보안 연구팀을 이끌어 학술대회 발표 8편을 완성했습니다.

2025.05–2025.12
KISIA (Korea Information Security Industry Association)
역할
Crew Leader
성과
ICT융합보안 우수크루상

개요

소프트웨어 개발, 배포, 운영, 실행 단계별로 AI 보안 연구 네 갈래를 진행했습니다.

역할

크루장으로 전체를 총괄하고 DeFi 취약점 탐지와 LLM 보안 두 팀의 팀장을 맡았습니다.

성과

학술대회에 8편을 발표해 5편이 수상했고 ICT융합보안 우수크루상을 받았습니다.

참여 규모
4개 대학 10명

성신 6, 서울여 2, 덕성 1, 한라 1명

학술대회 발표
8편

WISA 1, ACK 6, 융합보안학회 1편

수상 논문
5편

이 중 3편에 공저자로 참여

문제접근결과실무 활용발표자료

문제

내용

대학이 다른 10명이 6개월 안에 검증 가능한 연구 결과를 내야 했습니다.

초기 계획
탈중앙 금융(DeFi) 취약점 전체를 정적 분석과 LLM으로 탐지하려 해 범위가 넓었습니다.
중간 점검
계약 코드 전체를 LLM에 넣자 입력 한도를 넘었고 탐지 정확도도 낮았습니다.

접근

내용

연구 주제를 소프트웨어의 개발, 배포, 운영, 실행 단계별로 나누고 단계마다 팀을 구성했습니다.

범위 조정
LLM 입력을 함수 단위로 줄였고 일반화가 어려운 가격 정보 규칙은 접근 제어 탐지로 바꿨습니다.
평가 기준
중간보고 때 팀마다 데이터와 비교 대상을 정했고 접근 제어 연구는 지표를 바꿔 재실험했습니다.
일정 관리
격주 회의에서 산출물별 마감일과 진행 상태를 표로 점검했고 LLM 보안 팀 구성도 바꿨습니다.

결과

내용

학술대회에 8편을 발표했고 이 중 5편이 수상했습니다.

대표 산출물
비즈니스 로직 취약점 논문이 국가보안기술연구소장상을, 어텐션 기반 탐지 논문이 회장상을 받았습니다.
내 참여
8편 중 6편에 저자로 참여했고, 그중 3편이 수상했습니다.
그 밖에
해킹 사고 617건 데이터셋, 공개 라이브러리 1건, 코드 저작권 2건도 냈습니다.

실무 활용

내용

외부 기관과 함께하는 과제에서 범위와 검증 기준, 일정을 정리하는 데 쓸 수 있습니다.

활용 장면
여러 기관과 사람이 참여해 정해진 기간 안에 결과물을 내야 할 때입니다.
활용 방법
주제마다 데이터와 비교 대상을 먼저 정하고, 막힌 과제는 범위를 줄여 마감 안에 완성합니다.
