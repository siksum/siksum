SafeDevAnalyzer

스마트 컨트랙트를 배포하기 전에 코드와 취약점을 확인하는 VS Code 도구입니다.

문제와 구현

  • Web3 입문 개발자가 스마트 컨트랙트를 배포하기 전에 코드와 취약점을 점검할 수 있도록 개발, 테스트, 보안 분석 기능을 하나의 VS Code 도구로 만들었습니다.
  • 3인 팀의 팀장으로 Slither 기반 분석 코어와 컴파일 파이프라인을 구현했습니다. 탐지 결과는 원인, 공격 시나리오와 개선안을 담은 국문 및 영문 Audit Report로 제공해 개발자는 수정 방향을 확인하고 검토자는 배포 전에 남은 위험을 파악할 수 있게 했습니다.
