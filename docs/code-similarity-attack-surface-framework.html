코드 유사성 비교 기반의 스마트 컨트랙트 공격 표면 분석 프레임워크

오픈소스 컨트랙트를 수정해 쓸 때 원본에서 달라진 코드를 먼저 찾아 우선 검토하는 방법입니다.

제안 배경

내용

복제한 오픈소스를 수정하다 생긴 결함을 바뀐 곳부터 찾는 절차가 없었습니다.

상황
스마트 컨트랙트는 배포 후 고칠 수 없어 코드 결함이 곧 자산 피해로 이어집니다.
복제 관행
선행 조사에서 컨트랙트 33,073개 중 79.2%가 다른 코드를 복제한 것이었습니다.

선행 연구

내용

기존 점검 도구와 코드 유사성 연구는 서로 연결되지 않았습니다.

점검 도구
정해진 패턴만 찾아 문법은 맞지만 설계 의도와 다른 동작을 놓칩니다.
유사성 연구
복제 여부를 식별하는 데 머물러 보안 점검으로 이어지지 않았습니다.

해결책

내용

원본과 수정본을 비교해 달라진 함수를 먼저 찾고, 그 부분부터 점검합니다.

유사도 계산
코드 구조를 그래프로 바꿔 신경망으로 어느 함수가 원본과 달라졌는지 계산합니다.
우선순위
유사도, 복잡성, 변경 빈도로 함수별 순위를 매겨 높은 함수부터 점검합니다.

입증

내용

실제 사고 2건에서 텍스트 비교로 드러난 변경 코드가 사고 원인과 일치했습니다.

실험 설정
Uniswap V2를 수정해 쓰다 사고가 난 두 프로젝트의 교환 함수를 비교했습니다.
결과
유사도는 84%와 65%였고 바뀐 상수와 삭제된 검증 줄이 사고 원인과 일치했습니다.
한계
텍스트 비교만 했고 신경망 학습과 탐지율 측정은 하지 않았습니다.

기여와 다음 단계

기여

수정된 코드에서 점검할 범위를 유사도 분석으로 미리 좁히는 절차를 제안했습니다.

역할
제1저자로 이 절차를 제안했습니다.
공격 유형
Uniswap V2를 수정한 코드에서 생길 수 있는 공격 유형 7가지를 정리했습니다.

후속 연구

텍스트 비교에 그친 실험을 구조 기반 학습과 탐지 검증으로 넓히는 것이 과제입니다.

한계
텍스트 기반 유사도는 코드 구조나 논리 변화를 반영하지 못합니다.
향후 과제
신경망 학습을 적용하고 좁힌 영역에서 취약점이 실제로 탐지되는지 검증할 계획입니다.
