어텐션 패턴 분석을 활용한 다층 프롬프트 인젝션 탐지 프레임워크

금지어가 포함된 입력은 1단계 필터로 바로 차단하고, 통과한 입력만 모델의 주의 변화를 분석합니다. 탐지 범위를 넓히면서 LLM 서비스의 응답 지연을 줄였습니다.

제안 배경

내용

악성 지시를 정상 문장처럼 숨길 수 있어 기존 입력 검증으로 막기 어렵습니다.

공격 방식
입력에 악성 지시를 섞어 AI 언어 모델(LLM)이 정책을 우회하게 만드는 공격입니다.
어려운 이유
자연어는 형식이 고정되어 있지 않고 공격도 문맥 조작으로 정교해졌습니다.

선행 연구

내용

기존 방법은 정확도, 지연 시간, 비용을 함께 만족시키지 못했습니다.

금지어 필터
지연이 거의 없지만 표현을 바꾼 입력은 찾지 못합니다.
어텐션 분석
모델의 주의 변화로 공격을 찾지만 여러 유형을 고르게 탐지하기 어렵습니다.

해결책

내용

빠른 금지어 검사로 먼저 거르고, 통과한 입력만 모델의 주의 변화를 분석합니다.

1단계
다섯 범주의 금지어를 문자열 검색으로 찾아 즉시 차단합니다.
2단계
모델이 시스템 명령에 두는 주의를 점수로 계산해 임계값 이하이면 차단합니다.

입증

내용

악성 프롬프트 23개 중 19개를 탐지했고 지연은 어텐션 분석 단독보다 56% 짧았습니다.

실험 설정
여섯 유형의 악성 프롬프트 23개로 두 단독 방법과 비교했습니다.
결과
정확도는 두 단독 방법 각 43%, 제안 방법 83%였고 평균 지연은 956ms에서 420ms로 줄었습니다.
한계
23개 중 4개는 놓쳤고 지연과 비용은 금지어 필터 단독보다 큽니다.

기여와 다음 단계

기여

금지어 필터와 어텐션 분석을 단계적으로 결합하고 세 지표로 비교한 논문입니다.

참여
공저자로 참여했습니다.
논문의 기여
두 방법을 결합한 구조를 제안하고 프롬프트 인젝션을 여섯 유형으로 정리했습니다.

후속 연구

평가 규모가 작고, 내부를 볼 수 없는 모델에는 그대로 적용하기 어렵습니다.

한계
모델 내부 값에 접근해야 해서 API로만 제공되는 모델에는 쓰기 어렵습니다.
향후 과제
데이터셋을 넓히고 감정 호소형 공격에 대응하는 규칙을 더하는 것입니다.
